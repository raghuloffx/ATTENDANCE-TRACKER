## Overview

The Attendance Tracker is a prototype for recording and monitoring attendance in an organized way. Depending on the implemented features, users may be able to view attendance records, mark attendance, and check attendance summaries.

The project can be adapted for a classroom, college, training program, or workplace.

## Problem Statement

Manual attendance methods can take time, require extra paperwork, and make it difficult to review past records. This project explores a digital approach to make attendance recording and tracking more convenient.

## Objectives

- Provide a simple interface for attendance-related tasks.
- Make attendance records easier to record and review.
- Reduce manual effort and common record-keeping mistakes.
- Present attendance information in a clear, organized format.
- Create a prototype that can be extended with additional features.

## Features

- **Attendance summary:** Display totals or attendance percentages, if supported.

Possible roles for this project include:

- **Administrator / Teacher:** Manage people and attendance records, if this role is implemented.
- **Student / Employee:** View their own attendance, if this role is implemented.

The available roles depend on the features included in the current prototype.

## Typical Workflow

1. Open the Attendance Tracker application.
2. Sign in, if authentication is available.
3. Select a class, group, or person, depending on the interface.
4. Choose the attendance date.
5. Mark the appropriate status, such as Present or Absent.
6. Save the record.
7. Review the attendance list or summary.
